# SSD 精读笔记

《深入浅出 SSD 测试》+《深入浅出 SSD（第二版）》两本书的精读笔记，压成一页可检索的作战地图。

**在线看**：https://onanln.github.io/ssd-notes/

## 内容

| 部分 | 章节 |
|---|---|
| 一 · 先懂盘 | SSD 综述、主控 |
| 二 · 介质与固件 | NAND、FTL、ECC |
| 三 · 接口与协议 | PCIe、NVMe |
| 四 · 测试体系 | 测试概览、流程、管理、分类与设计、工具平台 |
| 五 · 部件与产线 | 主控验证、闪存测试、认证与仪器、SSD 测试 |
| 附录 | 全书要点速记 · 术语表（63 条）· 90 天上手路线 |

## 特点

- **单文件**：`index.html` 内嵌全部样式、脚本与检索索引，无外部依赖，断网可用
- **可检索**：按 `/` 或点搜索框，133 段索引全站跳转
- **好读**：目录跟随滚动、深色模式、阅读进度条、手机端抽屉目录
- **可打印**：每章自动分页，Ctrl/Cmd + P 直接出 PDF

## 来源说明

两本原书均为扫描版，笔记经 OCR 后人工结构化整理。书中的数值（P/E 次数、纠错能力、功耗等）多为举例型号的典型值，**做方案时请以具体 datasheet 为准**。
